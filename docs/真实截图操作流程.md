# 基本要求二与进阶部分：真实截图操作流程

## 一、打开真实终端

1. 手动打开 Windows Terminal，选择 **Ubuntu** 配置文件。如果只有 PowerShell，输入 `wsl -d Ubuntu` 进入 Ubuntu。
2. 最大化窗口，字体建议 16～18，使用白底黑字或对比清晰的配色。MLIR 图较长，建议字体 14～16，确保约 45 行能同时显示。
3. 输入下面两条命令。之后所有命令均在 **Ubuntu 的 Bash** 中执行，不在 PowerShell 中执行：

   ```bash
   cd '/mnt/d/vscodefile/编译系统上机大作业'
   pwd
   ```

4. 本机已有实验工具与 MLIR 工具目录，无需重新安装。可以先检查：

   ```bash
   clang --version
   opt --version
   riscv64-linux-gnu-gcc --version
   qemu-riscv64 --version
   ```

脚本 `scripts/report-evidence.sh` 会显示实际执行的命令（前缀 `+` 是 Bash 的命令追踪），读取项目源文件，并运行编译器和程序。它不会生成图片，也不会打印预先编造的运行结果。报错时不要截图作为成功证据，应先处理错误。

## 二、依次截取五张图

每张图先执行 `clear`，再运行对应命令。程序完成后，按 **Win + Shift + S**，框选终端内容，保留命令、路径、输出及底部成功状态。不要使用旧的 HTML 页面或图片模拟终端。

保存目录：`D:\vscodefile\编译系统上机大作业\LaTeX模板\figures\real`。

| 图 | 在 Ubuntu 中运行 | 保存文件名 | 截图必须包含 |
|---|---|---|---|
| 短路控制流 | `bash scripts/report-evidence.sh short` | `short_circuit.png` | verifier 命令；受保护除法与 phi；输入 0、4 的实际输出 |
| mem2reg | `bash scripts/report-evidence.sh mem2reg` | `mem2reg.png` | opt 命令；原文件的 alloca/load/store；生成文件的两个 phi；输入 10 输出 45 |
| 递归汇编 | `bash scripts/report-evidence.sh rv` | `recursive_rv.png` | 栈帧、保存 ra/s0、递归 call；交叉编译；QEMU 输入 7 输出 5040 |
| MLIR 降低 | `bash scripts/report-evidence.sh mlir` | `mlir_lowering.png` | 两个真实文件路径；SCF 的 scf.for；CF 的块参数、条件分支、回边 |
| 验证结果 | `bash scripts/report-evidence.sh results` | `results.png` | 六组 PASS；ALL PASS 269/269；VecAdd 16/16；程序输出 1 至 16 |

例如第一张：

```bash
clear
bash scripts/report-evidence.sh short
```

短路测试输出依次为 `0、2、0` 和 `1、2、1`，每个数字占一行。先确认两组输入均在截图内。mem2reg 的显示只筛选与变换有关的真实指令，因此不需要截取整个文件。递归图从实际源文件提取完整 factorial 函数。

MLIR 图会先重新执行完整 lowering 与 CPU 验证，再显示 SCF、CF 文件。两段输出合计约 40 行；如果超出屏幕，调小字体或增大窗口，保留两条 `cat` 命令以说明各段来源。结果图会重新运行全部 LLVM/RISC-V 检查，等待结束后再截图。

## 三、截图内容过长时使用真实编辑器

也可以在 VS Code 中打开以下文件，开启行号，分栏展示，并保留文件标签或路径：

- 短路：`prep/llvm_ir/short_circuit.sy` 与 `prep/llvm_ir/short_circuit.ll`，IR 定位第 14～35 行。
- mem2reg：`prep/llvm_ir/promote_demo.ll` 与执行脚本后生成的 `build/report-evidence/promoted.ll`，突出局部访存消失与两个 phi。
- MLIR：`prep/mlir/results/01_scf.mlir` 与 `prep/mlir/results/02_cf.mlir`，完整展示循环及回边。

这三类可以用真实编辑器截图替代对应终端图。递归运行与最终验证结果仍应使用真实终端截图。截图可以裁掉无关桌面区域，不应改写指令、输出或拼接不同运行的结果。

## 四、接入报告并重新编译

报告已设置自动选图：存在上述 PNG 时使用真实截图；不存在时使用实际代码摘录，不再使用原来的排版视图。文件名必须完全一致，尤其不要保存成 `results.png.png`。

五张图保存完成后，打开 PowerShell，执行：

```powershell
Set-Location 'D:\vscodefile\编译系统上机大作业\LaTeX模板'
& 'C:\Users\Alghy\AppData\Local\Programs\MiKTeX\miktex\bin\x64\xelatex.exe' -disable-installer -interaction=nonstopmode -halt-on-error main.tex
& 'C:\Users\Alghy\AppData\Local\Programs\MiKTeX\miktex\bin\x64\xelatex.exe' -disable-installer -interaction=nonstopmode -halt-on-error main.tex
```

生成文件：`D:\vscodefile\编译系统上机大作业\LaTeX模板\main.pdf`。打开 PDF，检查五张图是否清晰、命令是否完整、图题与正文引用是否对应。基础要求一的同学原始截图不改动。
