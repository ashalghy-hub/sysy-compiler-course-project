# 作业要求与验收清单

本文件根据本地总体要求全文及预备工作课件第 2–3 张整理。尚无截止日期、具体评测命令和答辩安排。

## 总体评分

课程平时成绩和期末考试各占 50%；资料列出的书面作业 15 分、上机作业 35 分属于课程最终分数。

| 模块 | 基础部分 | 进阶部分 | 合计 |
| --- | ---: | ---: | ---: |
| 预备工作 | 4 | MLIR 探索 1 | 5 |
| 词法分析 | 3 | 0 | 3 |
| 语法分析 | 3 | 0 | 3 |
| 类型检查与 SSA 中间代码 | 9 | 进阶语法 2 | 11 |
| 代码优化 | 0 | 4 | 4 |
| 目标代码与完整编译器 | 7 | 进阶语法 2 | 9 |
| 总计 | 26 | 9 | 35 |

**原总体要求的 track 口径**：基础 track 写为 `5+3+3+9+7=27`，竞赛 track 为 `2+4+2=8`。这将预备工作整体 5 分计入基础 track，但预备课件又把其中 1 分定义为进阶 MLIR。因此保留两种口径，不将“预备基本要求 4 分”误写为 5 分。总体说明写明进阶 8 分中功能检查占 3 分、答辩占 5 分。

## 预备工作

- [ ] 确定两人小组，可跨班；报助教备案，之后不应改变。
- [ ] 以 GCC 或 LLVM/Clang 等熟悉的工具研究预处理、编译及其内部阶段、汇编、链接。
- [ ] 用一个简单 C/C++ 程序获取各阶段输出，并分析与源程序的关系。阶乘或斐波那契做一个即可；机械重复多个程序不会增加分数。
- [ ] 设计 SysY 示例覆盖拟支持的数值运算、赋值、条件、循环、函数和进阶特性。
- [ ] 手写等价 LLVM IR 以及 ARM 或 RISC-V 汇编；生成目标程序并链接 SysY 运行时库，验证运行结果。
- [ ] 通过细微修改源码、调试/优化选项等探索阶段输出的变化，保留证据。
- [ ] 进阶：参考课件所给官方 VecAdd 示例，探索 MLIR 与 AscendNPU IR 逐层 lowering；配置困难时允许阅读文档、比较方言并报告探索过程。
- [ ] 合写一份科技论文结构的报告：题目、摘要、关键词、引言、工作与结果、结论、参考文献。
- [ ] 报告开始明确两人分工，基础工具链介绍简洁，探索结果详细。
- [ ] 提交 PDF；建议 LaTeX，但非强制。
- [ ] 两人都在小雅提交同一份最终报告，否则无法评分。

## 编译器基础功能

- [ ] int、变量与常量声明和初始化。
- [ ] 赋值、表达式/空语句、块、if/else、while、return、break、continue。
- [ ] `+ - * / %`，一元 `+ - !`，比较运算，逻辑 `&& ||` 与短路。
- [ ] 函数、调用、嵌套块作用域和注释。
- [ ] 类型检查、SSA 中间代码、ARM 或 RISC-V 汇编输出。
- [ ] 链接 SysY 运行时，完整构建并运行程序。

## 进阶功能

- [ ] 一维和多维数组及元素访问。
- [ ] 浮点常量、声明、存储和运算。
- [ ] 张量类型：总体要求列出，但所附语言规范未给出完整定义，实施前询问助教范围。
- [ ] 完整 mem2reg、不可达基本块消除、无用语句删除，合计 2 分。
- [ ] 完成 mem2reg 后任选两项或实现难度相当/更高的优化，另 2 分：稀疏条件常量传播、标量循环不变量外提、标量公共子表达式删除、函数内联、基于控制依赖图的激进死代码消除（含 dead-loop）。

总体要求在基础部分末尾有“并实现如下代码优化功能”但未列项目；优化的明确清单位于进阶部分。不要自行增补基础评分要求，向助教确认。

## 平台与最终交付

课程要求 Linux、C/C++，使用 GCC 或 LLVM/Clang 构建；目标架构 ARM 或 RISC-V，生成汇编再由 GCC/Clang 生成可执行程序。文档中的“Linux 系统 AT&T 风格”通常与 x86 术语有关，ARM/RISC-V 的实际汇编语法应以助教指定工具链为准，不能转而选择 x86。

- [ ] 描述实际支持的 SysY 子集，包含词法正则表达式和 CFG。
- [ ] 提交编译器全部源程序，包括采用的 Lex/Yacc 等源文件及 C/C++。
- [ ] 提供可复现的构建、运行和测试说明，准备助教功能检查。
- [ ] 准备答辩，两人能解释彼此模块及端到端流程。
- [ ] 引用公开实现时在具体代码注释标注来源；大量参考可能扣分，未注明的参考按抄袭处理、当次作业零分。

README、测试数据、构建说明、贡献记录是本项目建议的工程交付，不应与课程明文提交项混淆。
