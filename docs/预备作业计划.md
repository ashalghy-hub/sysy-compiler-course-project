## 实验一：语言处理系统

选一个合法、简单的 C 程序，例如阶乘。阶段输出保存在 `prep/artifacts/`，命令和版本保存在实验记录中。以下命令是待执行模板，需根据实际工具链修改：

```sh
mkdir -p prep/artifacts
clang --version
clang -E prep/examples/pipeline.c -o prep/artifacts/pipeline.i
clang -S -O0 prep/examples/pipeline.c -o prep/artifacts/pipeline.s
clang -c prep/artifacts/pipeline.s -o prep/artifacts/pipeline.o
clang prep/artifacts/pipeline.o -o prep/artifacts/pipeline
clang -S -emit-llvm -O0 prep/examples/pipeline.c -o prep/artifacts/pipeline.ll
```

分别解释：预处理中的宏和包含展开；词法/语法/语义检查；IR 生成和优化；指令选择与目标代码；汇编器的指令编码和重定位；链接器的符号解析、运行库链接。可用实际工具链的 `objdump`/`readelf` 查看目标文件和可执行文件。若分析前端 AST，可使用 Clang 的 AST dump，但它只是前端某一阶段的证据，不能代表整个编译过程。

## 实验二：三种等价实现

建议主示例使用 `getint`、`putint`、`putch`，通过自定义函数计算阶乘，加入条件分支、while 和局部变量。仅使用 0–12 的非负输入，避免 32 位 int 阶乘溢出。为未覆盖的语言特性另写小用例，而不是机械重复整个工具链实验。

| 用例 | 特性 | 输入/预期 | 验证方式 |
| --- | --- | --- | --- |
| 阶乘主程序 | 函数、赋值、while、if、乘法、运行库 | 0→1，1→1，5→120，12→479001600；输出换行 | SysY 参考、手写 IR、手写汇编相同 stdout/退出码 |
| 算术小程序 | `+ - * / %`、一元正负、优先级 | 自选合法整型值，手算预期 | 避免除零及未定义溢出 |
| 控制流小程序 | 比较、短路、break/continue、嵌套作用域 | 真/假和循环边界分支 | 检查短路右侧未执行 |
| 进阶数组 | 一维/二维、部分初始化、数组参数 | 固定小数组、手算结果 | 基础路线完成后执行 |
| 进阶浮点 | float 常量、运算、类型转换 | 固定可解释数据 | 根据运行库实际输出格式比较 |

1. 先为每个输入写预期 stdout、stderr（若有）与退出码。
2. SysY `.sy` 保持真实语法，不加入 C 的 `#include`；如使用 Clang 参考编译，命令行加 `-x c -include <sylib.h>`，只适用于 C/SysY 语义一致的用例。
3. 人工编写 `.ll`，解释每个基本块、分支、函数参数、返回值和运行库调用。工具生成的 `.ll` 可以辅助比较，不可冒充手写结果。
4. 人工编写 `.s`，记录 ISA、ABI、栈对齐、调用者/被调用者保存寄存器和运行库符号。
5. 三种实现采用相同目标 triple、浮点 ABI 和运行库分别构建。在硬件或对应 QEMU 用户态环境运行，记录 sysroot。
6. 比较全部输入的输出和退出码。仅链接成功不代表结果正确；本机 x86 可执行也不能替代 ARM/RISC-V 目标验证。

运行库尚未取得，目标 triple 和 sysroot 也未确认，因此这里不提供看似可直接执行的交叉链接命令。P0 确认后把实际完整命令写入实验记录。

## 实验三：探索编译选项

针对同一源码比较 `-O0`/`-O2`，再比较有无 `-g`；做一次小源码变化，例如常量替换或不可达分支。记录 IR/汇编的具体差异与原因，同时确认可观测输出一致。区分“工具观察结果”和“推测原因”，不能只贴大段编译输出。
