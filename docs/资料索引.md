## 应优先写入测试的规则

| 规则 | 实现和测试要求 | 来源 |
| --- | --- | --- |
| 数组形参后续维度是 ConstExp | `FuncFParam → BType Ident ['[' ']' {'[' ConstExp ']'}]`，校验可编译期求值 | 补充说明 §1 |
| 最小 int 值 | `-2147483648` 按 `-(long long)2147483648` 理解，词法阶段避免先溢出 | 补充说明 §2 |
| 普通表达式中的逻辑运算 | 实验允许 int/float/bool 表达式；`int a=5; return a+!a;` 合法，考虑隐式转换 | 补充说明 §3 |
| 浮点常量 | SysY 常量是 float；字符串尤其十六进制浮点的解析建议先以 double 计算再转 float | 补充说明 §4 |
| `++a` | 解析为 `+(+a)`，不是 C 的自增；值与 a 相同 | 补充说明 §5 |
| 常量数组维度 | `const int a=5; int b[a];` 可在 SysY 全局使用 | 补充说明 §6 |
| `putf` | 本课程不要求实现 | 补充说明 §7 |
| 逻辑短路 | `&&`、`||` 必须短路，关系和逻辑结果为 0/1 | 语言定义第 1–2 页 |
| 初始化 | 未初始化全局对象为 0/0.0，局部未初始化值不确定；数组初始化的隐式部分补零 | 语言定义第 6–7 页 |
| 数组 | 多维数组按行优先存储；数组参数传地址；第一维省略，后续维度指定 | 语言定义第 1、7–8 页 |
| 入口与作用域 | 唯一 `int main()` 无参数；定义后使用、块作用域、遮蔽、就近 else | 语言定义第 5、8 页 |

语言定义第 3–4 页对同名变量/函数、重叠局部作用域的表述，与第 5、8 页的重复定义和块遮蔽规则存在表述差异。暂按“同一作用域不重复定义，内层块允许遮蔽，顶层不重复定义”设计，需向助教核实。

SysY 不能简单等同于 C：`++a`、全局常量数组维度等差异会使直接拿 C 编译器作为测试参考产生错误。参考运行仅用于语义一致的用例；差异用例使用明确的预期结果。

## 运行时接口

整数/字符：`getint`、`getch`、`putint`、`putch`；数组：`getarray`、`putarray`；浮点：`getfloat`、`putfloat`、`getfarray`、`putfarray`；计时：`starttime`、`stoptime`。`putf` 见课程豁免规则。

运行时文档提供的是接口说明，目前目录中**没有** `sylib.h`、`libsysy.a`、`libsysy.so` 或运行时实现源码。需要取得与所选架构和 ABI 匹配的版本。真实 SysY 源码不包含 `sylib.h`，编译器需内置库函数信息；用 Clang 生成参考结果时可以通过命令行强制包含头文件。

计时不支持嵌套。运行时文档中的演示出现 `for`、`system`、字符串等，不能因此扩大课程 SysY 文法；接口示例与合法 SysY 源程序应区分。

课件封面和题目页包含雨课堂制卷提示，这些是模板提示，不是作业要求。
