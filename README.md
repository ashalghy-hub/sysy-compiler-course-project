# SysY 编译系统上机大作业

两人合作完成的 SysY 编译器课程项目。当前完成已有预备实验和袁煜杰负责的 LLVM IR / MLIR 实验及报告；完整编译器尚未实现，小组共同报告仍需整合搭档的分析和扩展手写汇编。

公开仓库：[ashalghy-hub/sysy-compiler-course-project](https://github.com/ashalghy-hub/sysy-compiler-course-project)。

## 当前方案

课程要求 Linux + C/C++，目标为 ARM 或 RISC-V 二选一。建议采用 Linux/WSL2、C++17、CMake、Clang/LLVM，目标优先考虑 RISC-V；这是待两位成员确认的工程建议，并非课程指定版本。先完成基础 track，再按时间实现进阶语法与优化。

袁煜杰（`ashalghy-hub`）负责预备作业基本要求二中的 LLVM IR、MLIR 进阶探索和对应报告；张龙飞（`3769lkj`）负责手写 RISC-V 汇编。后续编译器模块分工待双方确定，不安排日程。预备作业两人共同写一份 PDF，报告开头说明分工，**两人分别在小雅平台提交**。分组需报助教备案，之后不应改变。
