    \begin{abstract}
本实验通过编译工具的阶段输出研究语言处理流程，并设计六组 SysY 示例，
编写等价的 LLVM IR 与 RISC-V 汇编，涵盖算术、分支、循环、函数、数组和浮点转换。
通过参考程序、本机及 RV64 运行对照，共 269 项检查全部通过。
进阶部分结合 AscendNPU IR 官方 VecAdd 文档分析方言层级，
并执行上游 MLIR 从 Linalg 经 SCF、CF、LLVM 方言到 LLVM IR 的降低，
CPU VecAdd 的 16 个输出元素均正确。
\end{abstract}
\noindent\textbf{关键词：}SysY；LLVM IR；RISC-V；SSA；MLIR；等价性验证

\section{引言}

\subsection{实验背景与目的}
SysY 是全国大学生编译系统设计赛定义的简化 C 语言。本课程上机大作业要求实现一个
SysY 编译器（词法分析、语法分析、类型检查与中间代码生成、代码优化、目标代码生成），
目标平台为 RISC-V。本次预备工作是上机大作业的第一个模块，目的在于：
\begin{enumerate}
  \item 以 GCC / LLVM(Clang) 为研究对象，深入探究语言处理系统的完整工作过程，
        理解预处理器、编译器（前端与后端各阶段）、汇编器、链接器的功能；
  \item 熟悉 LLVM IR 中间语言与 RISC-V 汇编语言，
        设计覆盖 SysY 语言特性的示例程序，手写等价的 LLVM IR 与 RISC-V 汇编程序，
        链接 SysY 运行时库并验证运行结果的正确性；
  \item 为后续词法分析器、语法分析器、中间代码生成与目标代码生成等模块的实现
        建立直观认识与技术储备。
\end{enumerate}

\subsection{了解编译器工作过程}

以阶乘程序 \texttt{fact.cpp} 为例，通过命令行选项获取各阶段产物（表\ref{tab:cmd}）。

\subsubsection{实验方案}

\begin{lstlisting}[title={研究载体：阶乘程序 fact.cpp（PPT 示例）},language={C++}]
#include <iostream>
using namespace std;
int main()
{
    int i, n, f;

    cin >> n;
    i = 2;
    f = 1;
    while (i <= n)
    {
        f = f * i;
        i = i + 1;
    }
    cout << f << endl;
}
\end{lstlisting}

  编译（后端） & \texttt{g++ -S} / \texttt{riscv64-linux-gnu-g++ -S} & \texttt{fact.s}（汇编）\\

  链接 & \texttt{g++} / \texttt{riscv64-linux-gnu-g++ -static} & 可执行程序\\

\subsubsection{预处理器}
源程序仅 17 行，经 \texttt{clang++ -E} 预处理后得到 30194 行的
\texttt{fact.i}——C++ 标准库头文件 \texttt{<iostream>} 展开了数万行声明。

\subsubsection{编译器}
\paragraph{编译前端：生成 LLVM IR}
\texttt{clang++ -emit-llvm -S} 生成 111 行 LLVM IR（\texttt{fact.ll}），
关键片段如下：

\begin{lstlisting}[title={fact.ll 关键片段}]
@_ZSt3cin  = external global %"class.std::basic_istream", align 8
@_ZSt4cout = external global %"class.std::basic_ostream", align 8

define dso_local noundef i32 @main() #4 {
  %1 = alloca i32, align 4      ; return value
  %2 = alloca i32, align 4      ; i
  %3 = alloca i32, align 4      ; n
  %4 = alloca i32, align 4      ; f
  store i32 0, i32* %1, align 4
  %5 = call ... @_ZNSirsERi(@_ZSt3cin, i32* %3)      ; cin >> n
  store i32 2, i32* %2, align 4                      ; i = 2
  store i32 1, i32* %4, align 4                      ; f = 1
  br label %6
6:                                                   ; while (i <= n)
  %7 = load i32, i32* %2, align 4
  %8 = load i32, i32* %3, align 4
  %9 = icmp sle i32 %7, %8
  br i1 %9, label %10, label %16
10:
  %11 = load i32, i32* %4
  %12 = load i32, i32* %2
  %13 = mul nsw i32 %11, %12                         ; f = f * i
  ...
16:
  %17 = load i32, i32* %4, align 4
  %18 = call ... @_ZNSolsEi(@_ZSt4cout, i32 %17)     ; cout << f
  %19 = call ... @_ZNSolsEPFRSoS_E(%18, ... endl)    ; << endl
  ret i32 %20
}
\end{lstlisting}

\paragraph{编译后端：生成目标汇编}
分别用 \texttt{g++ -S}（x86\_64，AT\&T 风格）与
\texttt{riscv64-linux-gnu-g++ -S}（RISC-V）生成汇编，对比两者风格。

\subsubsection{汇编器}
\texttt{clang++ -c} 将汇编翻译为目标文件 \texttt{fact.o}，可用
\texttt{objdump -d} 反汇编查看机器码，\texttt{objdump -r} 查看重定位项。

\subsubsection{链接器}
链接阶段将目标文件与 C++ 运行库（\texttt{std::cin}/\texttt{std::cout}
所在的 libstdc++）组装为可执行程序。

\subsubsection{运行验证}
四种方式运行同一程序，结果一致（输入 5，输出 120），说明各阶段产物等价：

\begin{lstlisting}[title={运行验证},language=bash]
$ echo 5 | ./fact_x86                 # x86 可执行（g++ 链接产物）
120
$ echo 5 | lli fact.ll                # LLVM IR 解释执行
120
$ echo 5 | ./fact_fromll_x86          # 由 IR 直接重编译的可执行
120
$ echo 5 | qemu-riscv64 ./fact_rv64   # RISC-V 可执行（QEMU 模拟）
120
\end{lstlisting}

\section{总结与体会}
编译阶段输出展示了源程序向 IR、汇编、目标文件和可执行程序的转换。
手写 LLVM IR 与 RISC-V 汇编进一步说明短路求值、循环合流、数组布局和调用约定的实现方式。
六组程序在八条执行路径上输出一致，连同 mem2reg 对照，269 项检查全部通过。
MLIR VecAdd 实验展示了从高层计算结构到循环、分支和指针操作的逐层降低，
16 个输出元素全部正确。实验将语言语义、中间表示与目标执行结果建立了对应关系。
