    \begin{abstract}
本报告研究预备工作中的编译工具流程、LLVM IR 与 RISC-V 汇编编程，以及 MLIR 中端的多级降低。
基本要求二设计六组 SysY 示例并编写同源手写 LLVM IR 和 RISC-V 汇编，覆盖数值运算、
作用域、短路、循环、函数、数组与浮点转换。通过结构检查、参考编译及本机/RV64 运行对照，
33 组输入的八条执行路径及 mem2reg 对照共 269 项检查全部通过。
进阶部分查阅 AscendNPU IR 官方 VecAdd、架构与方言文档，另实际执行上游 MLIR
从 Linalg 经 SCF、CF、LLVM 方言到 LLVM IR 的降低，VecAdd 的 16 个元素均正确。
本机未配置 NPU/CANN，专有路线只报告文档研究；当前使用最小教学运行库，正式课程库尚待复测。
\end{abstract}
\noindent\textbf{关键词：}SysY；LLVM IR；RISC-V；SSA；MLIR；等价性验证

\subsection{实验背景与目的}
% 【待补全】用自己的话概述，可包含以下要点：
SysY 是全国大学生编译系统设计赛定义的简化 C 语言。本课程上机大作业要求实现一个
SysY 编译器（词法分析、语法分析、类型检查与中间代码生成、代码优化、目标代码生成），
目标平台为 RISC-V。本次预备工作是上机大作业的第一个模块，目的在于：
\begin{enumerate}
  \item 以 GCC / LLVM(Clang) 为研究对象，深入探究语言处理系统的完整工作过程，
        理解预处理器、编译器（前端与后端各阶段）、汇编器、链接器的功能；
  \item 熟悉 LLVM IR 中间语言与 RISC-V 汇编语言，
        设计覆盖 SysY 语言特性的示例程序，手写等价的 LLVM IR 与 RISC-V 汇编程序，
        链接 SysY 运行时库并验证运行结果的正确性；
  \item 为后续词法分析器、语法分析器、中间代码生成与目标代码生成等模块的实现
        建立直观认识与技术储备。
\end{enumerate}

\subsection{实验方案}

\begin{lstlisting}[title={研究载体：阶乘程序 fact.cpp（PPT 示例）},language={C++}]
#include <iostream>
using namespace std;
int main()
{
    int i, n, f;

    cin >> n;
    i = 2;
    f = 1;
    while (i <= n)
    {
        f = f * i;
        i = i + 1;
    }
    cout << f << endl;
}
\end{lstlisting}

\subsection{编译器}
\subsubsection{编译前端：生成 LLVM IR}
% 【待补全】要点提示：alloca/load/store 与局部变量的对应；icmp sle + br 与
% while 循环的对应；cin/cout 变为 std::istream/ostream 的成员函数调用
% （C++ 符号修饰，如 _ZNSirsERi）；全局量 @_ZSt3cin/@_ZSt4cout 与
% __cxx_global_var_init 初始化函数；类型系统 i32 等。
\texttt{clang++ -emit-llvm -S} 生成 111 行 LLVM IR（\texttt{fact.ll}），
关键片段如下：

\begin{lstlisting}[title={fact.ll 关键片段}]
@_ZSt3cin  = external global %"class.std::basic_istream", align 8
@_ZSt4cout = external global %"class.std::basic_ostream", align 8

define dso_local noundef i32 @main() #4 {
  %1 = alloca i32, align 4      ; return value
  %2 = alloca i32, align 4      ; i
  %3 = alloca i32, align 4      ; n
  %4 = alloca i32, align 4      ; f
  store i32 0, i32* %1, align 4
  %5 = call ... @_ZNSirsERi(@_ZSt3cin, i32* %3)      ; cin >> n
  store i32 2, i32* %2, align 4                      ; i = 2
  store i32 1, i32* %4, align 4                      ; f = 1
  br label %6
6:                                                   ; while (i <= n)
  %7 = load i32, i32* %2, align 4
  %8 = load i32, i32* %3, align 4
  %9 = icmp sle i32 %7, %8
  br i1 %9, label %10, label %16
10:
  %11 = load i32, i32* %4
  %12 = load i32, i32* %2
  %13 = mul nsw i32 %11, %12                         ; f = f * i
  ...
16:
  %17 = load i32, i32* %4, align 4
  %18 = call ... @_ZNSolsEi(@_ZSt4cout, i32 %17)     ; cout << f
  %19 = call ... @_ZNSolsEPFRSoS_E(%18, ... endl)    ; << endl
  ret i32 %20
}
\end{lstlisting}

\subsection{运行验证}
四种方式运行同一程序，结果一致（输入 5，输出 120），说明各阶段产物等价：

\begin{lstlisting}[title={运行验证},language=bash]
$ echo 5 | ./fact_x86                 # x86 可执行（g++ 链接产物）
120
$ echo 5 | lli fact.ll                # LLVM IR 解释执行
120
$ echo 5 | ./fact_fromll_x86          # 由 IR 直接重编译的可执行
120
$ echo 5 | qemu-riscv64 ./fact_rv64   # RISC-V 可执行（QEMU 模拟）
120
\end{lstlisting}

\section{总结与体会}
六组 SysY 示例、手写 LLVM IR、手写 RISC-V 汇编及其运行验证构成基本要求二的完整实验链。
SSA 合流、短路执行顺序、数组布局和调用约定需要同时满足结构与语义要求。
269 项检查均通过，但有限输入不能证明任意输入下的等价性。
MLIR 实验进一步展示索引映射、循环、控制流、内存描述符和目标接口如何逐层具体化，
CPU VecAdd 的 16 项元素检查通过；Ascend 专有方言部分按文档研究保留清晰证据边界。

完整源码、手写汇编、命令和输出见 \path{prep/llvm_ir/}；MLIR 检查点见 \path{prep/mlir/results/}。
实验可分别通过 \path{prep/llvm_ir/verify.py} 和 \path{prep/mlir/run_lowering.py} 复现。
本机链接的是最小教学运行库，取得课程正式库后需复测。
本报告保留基本要求一已有材料，其待补分析和图示仍须在最终提交前完善；
